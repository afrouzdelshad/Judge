## Approach

For each trajectory I looked at the **angular directions of the large‑radius excursions** (the "lobe tips"). Plotting θ = atan2(y,x) at each radial maximum, each trajectory shows a discrete set of preferred directions, uniformly spaced by 360°/N.

Examples:

- **O**: excursion angles cluster only at ≈ +55° and ≈ −128° → spacing 180° → N = 2
- **A**: ≈ +50°, −70°, +172° → spacing 120° → N = 3
- **B**: 47, 17, −13, −44, −74, −103, −133, −164, 167, 137, 106, 76 → spacing 30° → N = 12
- **T**: 46, 28, 12, −6, −23, −40, −57, −74, −91 … → spacing ≈17.1° → N = 21
