## Approach

For each trajectory I computed the polar angle θ = atan2(y,x) at the peak of each large radial excursion. The excursion peaks land on a discrete set of directions that advance by a fixed increment Δθ each burst; the lobe count is N = 360°/Δθ.

Examples:
- **A**: peaks at ≈ +50°, −70°, +172° → Δθ = 120° → N = 3
- **B**: peaks at 47°, 16°, −13°, −44°, −74°, −103°, … → Δθ ≈ 30° → N = 12
- **T**: peaks at −5.8°, −22.7°, −39.6°, −56.9°, −74.5°, −91°, … → Δθ ≈ 17.1° → N = 21
