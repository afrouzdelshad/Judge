## Approach

Each trajectory makes large radial excursions ("spikes"). For an N‑lobe system the spike directions θ = atan2(y,x) take only N discrete values, advancing by −360°/N each excursion. So I computed the angle at every large‑radius event and measured how many steps it takes to sweep a full 360°.

Examples:
- **A**: spike angles ≈ 54°, −71°, 172°, 50°… → step ≈ −120° → N = 3
- **O**: 58°, −130°, 56°, −128°… → step ≈ −180° → N = 2
- **B**: 47°, 16°, −13°, −44°, −73°, −103° … → step ≈ −30° → N = 12
- **T**: 46°, 28°, 12°, −6°, −23° … → step ≈ −17.1° → N = 21
