## Approach

For each trajectory I computed the polar angle θ = atan2(y, x) at the outer (large‑radius) excursions. In a multi‑lobe attractor these excursions cluster at N equally‑spaced angles (2πk/N), so counting the distinct angular clusters (equivalently, 360°/Δθ) gives N.

Examples:
- **A**: outer peaks at ≈180°, 137°, 92°, 47°, 2°, −43°, −88°, −133° → Δθ ≈ 45° → N = 8
- **B**: ≈192°, 120°, 48°, −24°, −96° → Δθ ≈ 72° → N = 5
- **G**: ≈47°, −13°, −73°, −133°, 167°, 107° → Δθ ≈ 60° → N = 6
- **S**: only two opposed directions (≈57°, ≈−123°) → N = 2
- **C/Q**: Δθ ≈ 21.2° → N = 17; **L**: Δθ ≈ 17.1° → N = 21; **N**: Δθ ≈ 19.0° → N = 19

Reassuringly, trajectories sharing the same N land on identical angular sets (A&R, B&I, C&Q, E&P&T, H&O), which validates the extraction.
