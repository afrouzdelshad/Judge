## Method

For each trajectory I converted the raw (x, y) points to polar angle θ = atan2(y, x), then tracked the angle of the **large‑radius excursions** (the outer sweep of each lobe). In every case the orbit hops from lobe to lobe by a constant angular increment Δθ, so N = 360°/Δθ (verified by counting how many hops close one full revolution).

Examples:
- **A**: outer sweeps at ≈ −178°, 138°, 92°, 48°, 3°, −44°, −89°, −131° → Δθ ≈ 45° → N = 8
- **B**: −168°, 122°, 48°, −24°, −95° → Δθ ≈ 72° → N = 5
- **C**: 88°, 66°, 45°, 25°, 4°, −18°, … → Δθ ≈ 21.2° → N = 17
- **S**: only two outer clusters (≈ +53° and ≈ −125°, 180° apart) → N = 2
- **L**: Δθ ≈ 17.1° (21 hops to close the circle) → N = 21
- **N**: Δθ ≈ 19.0° (19 hops) → N = 19
