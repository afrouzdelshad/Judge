## Analysis Approach

For each trajectory I converted (x,y) → polar angle θ = atan2(y,x) and tracked it over time. In every run the orbit **dwells** at a fixed angular direction (radius pulsing in/out), then hops to the next direction, always precessing in one sense. The dwell directions are equally spaced, so

**N = 360° / (angular hop between successive dwell directions)**

The angular "wobble" inside a dwell also scales with 2π/N, which confirmed the readings.

Sample results:
- **A**: dwells at −88°, −132°, −178°, 138°, 93°, 47°, 2°, −41° → hop ≈ 45° → N = 8
- **H**: only two dwell centers, ≈ +49° and ≈ −131° (Lorenz‑like) → N = 2
- **M/O**: hops of ≈ 60° → N = 6
- **E/P/T**: hops of ≈ 32.7° → N = 11
- **D**: hops of ≈ 25.7° → N = 14
- **J**: hops of ≈ 22.5° → N = 16
- **C/L/N/Q**: hops of ≈ 18.9° (19 dwell directions per revolution) → N = 19

A useful consistency check: trajectories sharing an identical initial condition (e.g. C,D,E,I,J,O,S all start at (0.591, 22.52)) each landed in a *different* N‑class, and members of a class always showed the *same* set of lobe angles.

**Final N assignment:** 2 → {H,S}; 6 → {M,O}; 8 → {A,B,F,G,I,K,R}; 11 → {E,P,T}; 14 → {D}; 16 → {J}; 19 → {C,L,N,Q}

Group sizes are uneven (7,4,3,2,2,1,1), so my best single estimate for Y is ~3.
