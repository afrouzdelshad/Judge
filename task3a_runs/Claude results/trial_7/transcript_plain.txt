## Analysis

Each trajectory starts from one of **5 distinct initial conditions**, each used 4 times — so each N‑group contains exactly one trajectory from each IC. That gives a strong consistency check.

To find N, I tracked the polar angle θ = atan2(y,x) over time. In these multi‑lobe attractors the angle sits on a plateau while spiraling within one lobe, then jumps to the next lobe. The plateau‑to‑plateau spacing equals 360°/N.

**Examples of measured lobe angles:**

|---|---|---|---|
| H | 141, 51, −40 | ≈90.5 | 4 |

| C | −153, −170, −187, −206, −224, −241 | ≈17.9 | 20 |
| N | −7.5, −25.5, −43.8 | ≈18.1 | 20 |

Since 360/4 = 90, 360/11 = 32.7, 360/16 = 22.5, 360/20 = 18, the four groups are N = 4, 11, 16, 20 — and each group indeed contains one trajectory from each of the five initial conditions.
