## Analysis Approach

For each trajectory I computed the polar angle θ = atan2(y, x) at times of large radius (the "lobe visits"), since lobes sit at fixed angular positions around the central axis.

**Trajectories A–K, M–T:** all show radial maxima clustered at essentially the same five angles:

≈ **+47°, +120°, −168°(192°), −96°, −24°**

i.e. lobes spaced ~72° apart → **N = 5**. Examples:

- A: −168° (t≈15.5) → 122° (t≈17.0) → 51° (t≈18.8) → −27° (t≈19.5) → −95° …
- B: −93° → −167° → 120° → 48° → −26° …
- S: 121° → 48° → −22° → −95° → −166° …
- T: −23° → −95° → −167° → 120° → 50° …

Each advances by ~72° per excursion, cycling through only 5 angular sectors.

The lobes are spaced ~**36°**, and the orbit marches monotonically through **ten** distinct sectors (11°, 47°, 82°, 119°, 154°, 192°, 228°, 263°, 299°, 335°) — confirmed again at late times (t ≈ 89 → 93 → 95: −98° → −133° → −169°). No other trajectory ever reaches the intermediate directions (11°, 82°, 154°, −61°, −132°) at large radius.

So L has N = 10 while all others have N = 5.
